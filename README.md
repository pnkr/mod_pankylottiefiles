# Panky Lottie Files (Joomla 6)

Lottie and [dotLottie](https://lottiefiles.com/dotlottie) animations for Joomla 6.
Browse animations at https://lottiefiles.com.

The package contains:

| Extension | What it does |
|---|---|
| **Module** – Panky Lottie Animation | One or more animations in a module position, as a stack, grid or slider. Live preview while editing. |
| **Content plugin** – Panky Lottie | Turns `{lottie src="images/animation.lottie"}` in articles into an animation. |
| **Editor button** – Lottie | Inserts a `{lottie}` tag from a small dialog. |

## Requirements

- Joomla 6.0 or later
- PHP 8.3 or later

Version 2.x does not install on Joomla 4 or 5; use 1.x there. Updating from 1.x
converts existing module settings automatically.

## Features

- `.lottie` and `.json` files, from the Media Manager or any URL
- Play automatically, when scrolled into view, on hover (stop, pause or reverse on leave), on click, or linked to page scroll
- Frame ranges, named markers and `.lottie` themes
- Play/pause button, alternative text or decorative mode, and `prefers-reduced-motion` support
- Responsive sizing with an aspect ratio and fit options
- Optional link around each animation
- The player (dotlottie-wc, about 85 KB plus a 1.2 MB WASM engine) loads only when an
  animation nears the viewport, and is served from your own site, with no CDN requests

### Media Manager setup

To pick `.lottie` and `.json` files in the Media Manager, open **System → Media → Options** and add:

- `json,lottie` to **Legal Extensions** and **Legal Document Extensions**
- `application/json,application/zip` to **Legal MIME Types**

URLs work without this. For the best performance, make sure the server sends
`.wasm` files as `application/wasm` (it still works otherwise, just slower).

### Content plugin syntax

```
{lottie src="images/hello.lottie" alt="Waving hand" trigger="viewport" loop="1"}
```

Optional attributes: `trigger` (autoplay, viewport, hover, click, scroll), `hover-out`
(stop, pause, reverse), `loop`, `controls`, `reduced-motion`, `decorative` (1/0), `speed`,
`mode` (forward, reverse, bounce, reverse-bounce), `width`, `height`, `ratio` (e.g. 16/9),
`fit` (contain, cover, fill, fit-width, fit-height, none), `background` (#RRGGBB),
`segment` (e.g. 10-60), `marker`, `theme`, `link`, `target` (_blank). Write a double
quote inside a value as `&quot;`.

### Template overrides

- Module wrapper: `templates/<template>/html/mod_pankylottiefiles/default.php`
- Single player, used by the module and the plugin: `templates/<template>/html/layouts/pankylottie/player.php`
